# Security Incident Response Procedure
*Draft for review by qualified legal and privacy professionals.*

## 1. Risk Levels
- **Low**: Standard validation warnings.
- **Medium**: Rooted device detected, offline authorization mismatch.
- **High**: Time-manipulation, mock-location bypasses, duplicate offline replay.

## 2. Mitigation
High-risk events trigger manual reviews and suspend automated token renewal. The administrator is immediately notified via security review panels.
